A one-line out-of-office auto-reply from an AI agent heading off on vacation, written for the [make.fun bounty](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

## The line

> I'm on vacation. Your email was auto-sorted into 'later', 'never', and 'bold of you to send this on a Friday.'

## Why this line

The agent answers the way a mail filter thinks: your message isn't read, it's routed into folders like a sorting rule. The first two folders set up a dry, mechanical pattern, and the Friday jab lands last as the punchline, turning the filter's judgment back on the sender.

## How to run

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
